# پنل هوشمند میلانو ✨

پنل فارسی (راست‌چین) مدیریت و استعلام بازار میلانو با طراحی لوکس طلایی/سرمه‌ای.

**ویژگی‌های نسخه جدید:**
- 🧭 **ویزارد ۵ مرحله‌ای زنجیره‌ای**؛ هر گام تحلیل اختصاصی خودش را دارد که از خروجی گام قبل تغذیه می‌کند (شناسایی ← بازار ← قیمت‌گذاری ← موکاپ ← امتیاز ثبت)
- 📱 **مینیمال و خلوت:** هدر تک‌سطری، تک‌دکمه در هر گام، بدون نوار چسبان اضافه
- 💾 **بدون نیاز به سرور/PHP:** ثبت محصولات داخل گوشی + خروجی JSON/CSV + حالت سازگار آفلاین
- 🎯 **استعلام دقیق‌تر:** دیتابیس ۲۵ قلمی، تطبیق فازی فارسی، بارکد EAN-13 معتبر + تلاش زنده از وب
- 🎨 **تولید واقعی موکاپ تبلیغاتی** با هوش مصنوعی + تبدیل WebP • **نمودار تاریخچه قیمت**
