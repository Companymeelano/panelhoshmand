# پنل هوشمند میلانو ✨

پنل فارسی (راست‌چین) مدیریت و استعلام بازار میلانو با طراحی لوکس طلایی/سرمه‌ای.

**ویژگی‌های نسخه جدید:**
- 🧭 **ویزارد ۵ مرحله‌ای زنجیره‌ای**؛ هر گام تحلیل اختصاصی خودش را دارد که از خروجی گام قبل تغذیه می‌کند (شناسایی ← بازار ← قیمت‌گذاری ← موکاپ ← امتیاز ثبت)
- 📱 **مینیمال و خلوت:** هدر تک‌سطری، تک‌دکمه در هر گام، بدون نوار چسبان اضافه
- 💾 **بدون نیاز به سرور/PHP:** ثبت محصولات داخل گوشی + خروجی JSON/CSV + حالت سازگار آفلاین
- 🎯 **استعلام دقیق‌تر:** دیتابیس ۲۵ قلمی، تطبیق فازی فارسی، بارکد EAN-13 معتبر + تلاش زنده از وب
- 🎨 **تولید واقعی موکاپ تبلیغاتی** با هوش مصنوعی + تبدیل WebP • **نمودار تاریخچه قیمت**

## ⚙️ راه‌اندازی هوش مصنوعی (۳۰ ثانیه)

کلیدها **عمداً داخل کد قرار نگرفته‌اند** تا در گیت‌هاب لو نروند. در پنل دکمه **«تنظیمات»** (بالای صفحه) را بزنید:
- **اتصال فروشگاه:** آدرس API + کلید را وارد و «تست صحت اتصال» را بزنید
- **هوش مصنوعی:** کلید Groq / Gemini / OpenAI / GapGPT / Stability را وارد و دکمه «تست» هر کدام را بزنید تا چراغ سبز شود
- **انتخاب موتور:** حالت «خودکار هوشمند» قوی‌ترین گزینه را انتخاب می‌کند و در صورت توقف یکی، جایگزین بعدی خودکار وارد می‌شود
- لودر AI دکمه **انصراف** دارد؛ در صورت هنگی، بدون بستن برنامه عملیات لغو می‌شود

## ☁️ اتصال دیتابیس MySQL هاست (اختیاری ولی پیشنهادی)

بدون سرور هم برنامه کامل کار می‌کند (داده‌ها روی دستگاه). ولی برای **ذخیره ابری، چند دستگاه و امنیت واقعی** این ۳ قدم را بروید (۲ دقیقه):

1. **آپلود:** از cPanel → File Manager وارد پوشه پنل شوید (مثلاً `public_html/universal`) و فایل **`api.php`** را کنار `index.html` آپلود کنید.
   - امنیتی (پیشنهادی): همان‌جا فایل `db_config.sample.php` را با نام **`db_config.php`** کپی و رمز واقعی را داخلش بگذارید؛ در این صورت رمز اصلاً از اپ ارسال نمی‌شود. (این فایل در `.gitignore` است و داخل گیت نمی‌رود.)
2. **تنظیمات اپ:** دکمه «تنظیمات هوشمند» → بخش «دیتابیس MySQL هاست» → آدرس `api.php` (مثلاً `https://ainetmee.ir/universal/api.php`) + هاست (`localhost`) + نام دیتابیس + کاربر + رمز → **«تست اتصال»** (باید سبز شود).
3. **«ساخت جداول»** را بزنید؛ لودینگ درصددار هر ۳ جدول (`products` ،`price_history` ،`app_meta`) را می‌سازد و راستی‌آزمایی می‌کند.

بعد از آن: هر بار ورود، سلامت اتصال خودکار چک می‌شود (نقطه روی دکمه تنظیمات: سبز/قرمز)، تاریخچه به‌صورت خودکار ادغام و با دکمه «همگام‌سازی» در مودال تاریخچه همه‌چیز با سرور سینک می‌شود. ثبت نهایی محصول هم در پس‌زمینه داخل جدول `products` ذخیره می‌گردد.

> ⚠️ رمز دیتابیس را فقط داخل اپِ دستگاه خودتان (یا `db_config.php` روی سرور) نگه دارید و هرگز داخل گیت/چت عمومی نفرستید.
