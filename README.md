# پنل هوشمند میلانو — Meelano Smart Panel v2

> طراحی و توسعه: **Milad Yaghoobi** · **Meelano Studio Design**

سامانهٔ یکپارچهٔ مدیریت انبار، استعلام قیمت بازار (ترب/دیجی‌کالا)، قیمت‌گذاری قابل حسابرسی،
تصویرسازی WebP و ویدیو — با **مسیریابی هوشمند بین ۱۲ موتور هوش مصنوعی**.

📄 برای آنالیز فنی کامل، عیب‌یابی نسخهٔ قبل و معماری: **[ANALYSIS.md](ANALYSIS.md)**

---

## اجرا و تست

```bash
# تست واحد + یکپارچه (۳۹ تست روی کد واقعی)
php tests/run.php

# ساخت آیکون‌های اندروید از تصویر مرجع
python3 tools/build_icon.py
```

## ساختار صفحه‌ها

| صفحه | مسیر | کاربرد |
|------|------|--------|
| پنل کالا | `index.php` | ثبت/تحلیل/قیمت‌گذاری/تصویر کالا |
| انبار | `products.php` | فهرست، جست‌وجو، ویرایش، حذف |
| تنظیمات | `settings.php` | دیتابیس + ساخت جداول + کلیدهای AI + مسیریابی + امنیت |
| ورود | `login.php` | دسترسی مدیر (رمز پیش‌فرض `meelano-admin`) |

## نکات امنیتی مهم

- کلیدهای API فقط سمت سرور و **رمزنگاری‌شده (AES-256-GCM)** در `config/settings.php` نگهداری می‌شوند
  و این مسیر در `.gitignore` است.
- کلیدهایی که قبلاً به‌صورت متن آشکار رد و بدل شده‌اند را **باطل و دوباره صادر** کنید.
- در هاست اشتراکی، `host` دیتابیس باید `localhost` باشد (پورت ۳۳۰ از بیرون بسته است).

## اندروید

بستهٔ `android/` شامل `MainActivity` (WebView تمام‌صفحه) و آیکون تطبیقی سه‌بعدی است:
- `android/app/src/main/res/mipmap-*/` — PNG در همه چگالی‌ها + لایه‌های adaptive/monochrome
- `android/app/src/main/res/mipmap-anydpi-v26/ic_launcher.xml` — آیکون تطبیقی + Themed Icons
